## Claude Code

- Shared project instructions live in `AGENTS.md`, so contributors using other AI tools get the same rules. Edit that file, not this one.
- Personal, per-developer instructions go in `CLAUDE.local.md`, which is gitignored.
- Never add imports of files outside the repository here, e.g. `@~/...`: every contributor would get an approval prompt for files they don't have.
